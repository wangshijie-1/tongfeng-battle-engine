# TongFeng 同锋

一个跑在 aarch64 嵌入式 Linux 开发板上的贪吃蛇，支持单人 / 双人对战、暂停、存档和全局配置。没有使用 SDL、ncurses 之类的图形库——渲染、文字、键盘输入都直接构建在 Linux 底层接口之上，这也是这个项目主要的练习内容。

## 构建

交叉编译工具链已在 CMakeLists.txt 中配置好：

```bash
mkdir build && cd build
cmake ..
make        # 产物输出至 bin/GreedySnake
```

在开发板上运行（需要帧缓冲设备权限）：

```bash
./bin/GreedySnake
```

## 架构

引擎用一个状态机调度全部流程：主菜单、单人、双人、暂停、游戏结束。输入统一由 KeyInput 采集，引擎按当前状态分发给对应的处理器；对局逻辑按节拍驱动，渲染走增量更新。

```
┌────────────────────────── GameEngine (状态机调度) ─────────────────────────┐
│   MENU ── SINGLE_PLAYER ── TWO_PLAYER ── PAUSED ── GAME_OVER               │
│        统一输入轮询 → 按状态分发 → 节拍驱动 update / render                 │
├─────────── modes/ ─────────────┬────────────── core/ ──────────────────────┤
│  SingleMode  单人对局           │  Screen     /dev/fb0 mmap 单例           │
│  TwoPlayerMode 双人对战         │  KeyInput   evdev + 终端双通道输入       │
│  MenuMode    菜单 / 配置        │  Font       8×8 / 16×16 点阵字体        │
│              存档 / 继续        │  Render     增量渲染                     │
│                              │  Snake / Board / Food  纯逻辑              │
└──────────────────────────────┴────────────────────────────────────────────┘
```

## 一些实现细节

**渲染**：直接 mmap /dev/fb0 写显存。画矩形时对行列做越界裁剪——显存是线性一维数组，坐标越界会换行写到下一行，食物就会“卡在两个格子中间”，这个 bug 是裁剪之后根治的。所有布局按 ioctl 读到的真实分辨率计算，不写死，换屏幕不用改代码。

**文字**：自己写的点阵字体模块，8×8 英文数字加 16×16 中文，按 UTF-8 解析，支持整数倍缩放。字模不是手点的，是 Python 脚本从系统 TTF 提取后生成的 C 数组。

**输入**：两条通道——终端的 ANSI 转义序列（开发时在 PC 上调试用），和 Linux evdev 驱动级事件（板子上实际用的）。evdev 通道会扫描 /dev/input/event*，按设备能力位识别出键盘，event 编号变了自动重连，支持热插拔。

**双人对战**：这个模块的难点在于——两条蛇可以各自加速，速度不同，节拍间隔就不同；如果两条蛇的线程各自直接往显存里画，写入会交错，画面就花了。所以最终把逻辑和渲染拆开：每条蛇一个线程只管按自己的速度移动，渲染统一由引擎以 10ms 固定帧率增量绘制。共享的蛇身数据用 mutex 保护，生死 / 胜负 / 暂停标志用 atomic；死亡判定只在某条蛇真正移动之后做，不对未移动的帧做预测判定。暂停时线程冻结而不是销毁，恢复后无缝续跑。

**暂停与提示文字的还原**：遮罩画上去之前先把覆盖区域的原始像素缓存下来，退出时整块写回，不需要整屏重绘，没有闪烁和残留。

**存档与配置**：切回菜单时自动保存对局（蛇身、方向、速度、体力全部序列化），下次从“继续游戏”原样恢复；配置面板可以调格子大小和起步 / 加速速度，改动经确认后生效。

## 目录结构

```
.
├── GameEngine.cpp / .h   引擎：状态机、输入分发、节拍、存档、暂停缓存
├── main.cpp              入口
├── core/                 底层设施：Screen / KeyInput / Font / Render / Snake / Board / Food
├── modes/                游戏模式：SingleMode / TwoPlayerMode / MenuMode
├── _gen_*.py             字模与素材生成脚本
└── CMakeLists.txt        aarch64 交叉编译配置
```
