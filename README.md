# TongFeng 同锋

运行于 aarch64 嵌入式 Linux 开发板的贪吃蛇游戏，支持单人与双人对战。渲染、输入、字体均直接基于 Linux 底层接口实现，未使用 SDL、ncurses 等图形库——项目的主要目的是练习 Linux 系统级编程。

## 功能

- 单人 / 双人本地对战（P1：WASD + R 加速；P2：方向键 + `/` 加速）
- 加速消耗体力，体力耗尽强制恢复后才能再次加速
- 暂停 / 恢复；暂停画面可无损还原
- 对局存档：切回菜单自动保存，下次"继续游戏"原样恢复
- 全局配置面板：格子大小、起步速度、加速速度（各三档）

## 构建与运行

交叉编译工具链已在 CMakeLists.txt 中配置好：

```bash
mkdir build && cd build
cmake ..
make        # 产物输出至 bin/GreedySnake
```

在开发板上运行（需要帧缓冲设备权限）：

```bash
./bin/GreedySnake
```

## 架构

GameEngine 以状态机调度全部流程，输入统一由 KeyInput 采集、按当前状态分发；对局逻辑按节拍驱动，渲染为增量更新。

```
┌────────────────────────── GameEngine (状态机调度) ─────────────────────────┐
│   MENU ── SINGLE_PLAYER ── TWO_PLAYER ── PAUSED ── GAME_OVER               │
│        统一输入轮询 → 按状态分发 → 节拍驱动 update / render                 │
├─────────── modes/ ─────────────┬────────────── core/ ──────────────────────┤
│  SingleMode  单人对局           │  Screen     /dev/fb0 mmap 单例           │
│  TwoPlayerMode 双人对战         │  KeyInput   evdev + 终端双通道输入       │
│  MenuMode    菜单 / 配置        │  Font       8×8 / 16×16 点阵字体        │
│              存档 / 继续        │  Render     增量渲染                     │
│                              │  Snake / Board / Food  纯逻辑              │
└──────────────────────────────┴────────────────────────────────────────────┘
```

## 设计说明

**渲染**：直接 mmap /dev/fb0 写显存。显存是线性一维数组，越界坐标会换行写到下一行，因此画点/画矩形时逐行列裁剪；棋盘尺寸按 ioctl 读取的真实分辨率计算，不依赖固定值，更换屏幕无需改代码。

**输入**：两个通道。终端 ANSI 转义序列用于 PC 上开发调试；板端使用 evdev 驱动级事件——扫描 /dev/input/event*，按设备能力位识别键盘，event 编号变化时自动重连，支持热插拔。

**字体**：8×8 ASCII 与 16×16 中文点阵，按 UTF-8 流式解析，支持整数倍缩放与居中。字模由 `_gen_*.py` 从系统 TTF 提取生成，汉字按需扩充。

**双人对战**：两条蛇各由一个线程驱动，按自身速度独立节拍移动（可各自加速、互不影响）。渲染不放在蛇线程内，由引擎以 10ms 固定帧率统一增量绘制，避免两线程交错写显存造成撕裂。共享蛇身数据以 mutex 保护，死亡/胜负/暂停等标志使用 atomic；死亡判定仅在蛇真实移动后执行。暂停时线程冻结而非销毁，恢复后无缝续跑。

**画面还原**：暂停遮罩与提示文字绘制前先缓存覆盖区域的原始像素，退出时整块写回，不需要整屏重绘。

## 已知限制

- 内置中文字模数量较少，仅覆盖界面所需文字；如需完整字形，建议替换为 FreeType + TTF
- 双人对战碰撞规则较简单（撞对方身 / 头碰头判死），无更复杂的对战机制

## 目录结构

```
.
├── GameEngine.cpp / .h   引擎：状态机、输入分发、节拍、存档、暂停缓存
├── main.cpp              入口
├── core/                 底层设施：Screen / KeyInput / Font / Render / Snake / Board / Food
├── modes/                游戏模式：SingleMode / TwoPlayerMode / MenuMode
├── _gen_*.py             字模与素材生成脚本
└── CMakeLists.txt        aarch64 交叉编译配置
```
